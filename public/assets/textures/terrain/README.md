# Terrain textures

Drop terrain texture assets in this folder.

Current expected placeholder sand texture filename:

- `sand_basecolor.jpg`

Use a seamless/tileable square image if possible. 1024x1024 or 2048x2048 is plenty for now.

Later this folder can also hold biome-specific textures such as:
- rock_basecolor.jpg
- deep_sediment_basecolor.jpg
- coral_ground_basecolor.jpg
